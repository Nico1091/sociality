# Sociality

Red social desarrollada como proyecto académico con HTML, CSS y JavaScript sin dependencias
de terceros en el lado del cliente.

## Qué incluye

| Módulo | Archivos | Función |
|---|---|---|
| Acceso y registro | `index.html`, `Registro.html`, `usuarios.js` | Alta de usuarios y validación de credenciales |
| Muro | `Muro.html`, `Muro.css`, `publicaciones.js` | Publicación y listado de contenidos |
| Panel de control | `Panel.html`, `Panel.css`, `Admin.js` | Administración de usuarios y publicaciones |

## Cómo ejecutarlo

Basta con abrir `index.html` en el navegador. No requiere servidor para la navegación básica.
